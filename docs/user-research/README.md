# Chef-Facing User Research

Research on the chef-side journey: discovering a kitchen, requesting a tour, and requesting
to apply — including guest → registered conversion and the experience of returning chefs.

## Starting point

Read the plan's §7 *Sequencing* first. The short version: instrument before you change
anything, capture a baseline on the current build, and only then ship the UI fixes — so the
before/after comparison is real rather than reconstructed.
